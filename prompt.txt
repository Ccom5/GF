Necesito que revises el código HTML de mis páginas y corrijas/agregues las etiquetas de Open Graph (OG) y Twitter Card en la sección <head>.  
Requisitos:  
1. Incluir al menos estas etiquetas OG:  
   <meta property="og:title" content="...">  
   <meta property="og:description" content="...">  
   <meta property="og:image" content="https://gf-amd.pages.dev/img/nombre-imagen.jpg">  
   <meta property="og:url" content="https://gf-amd.pages.dev/pages/entrada-p">  
   <meta property="og:type" content="article">  

2. Incluir estas etiquetas de Twitter Card:  
   <meta name="twitter:card" content="summary_large_image">  
   <meta name="twitter:title" content="...">  
   <meta name="twitter:description" content="...">  
   <meta name="twitter:image" content="https://gf-amd.pages.dev/img/nombre-imagen.jpg">  

3. Las URLs deben ser **absolutas con https://**, no relativas.  
4. La imagen debe ser JPG o PNG, con tamaño mínimo 1200x630 px y menos de 5MB.  
5. No colocar etiquetas inválidas dentro de <head> (ej: <img>, <iframe>).  
6. Mantener el <title> actual como base para `og:title` y `twitter:title`.  
7. Mantener la meta description si existe, y usarla para `og:description` y `twitter:description`.  

Corrige el HTML y muéstrame el bloque <head> completo ya validado.
